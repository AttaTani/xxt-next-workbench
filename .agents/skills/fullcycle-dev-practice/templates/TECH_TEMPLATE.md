## 一、方案现状审计与重构目标

### 1.1 现状技术债审计 (Technical Debt Audit)
- **DOM / 布局层**：嵌套过深、存在弹性盒坍塌隐患、未处理 safe-area。
- **状态流转层**：全局变量混乱、无统一状态机校验。
- **性能与开销**：过度重排重绘 (Reflow)、未销毁的事件监听器。

### 1.2 预期技术收益指标
- DOM 节点深度削减 $\ge 30\%$；
- 移动端滑动手势掉帧率降为 0；
- 状态更新完全受控并自动持久化。
