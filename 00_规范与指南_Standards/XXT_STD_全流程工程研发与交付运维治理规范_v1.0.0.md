# XXT - 学习通 VPS 自动化服务全流程工程研发与交付运维治理规范 (STD-001)

> **规范版本**：v1.0.0  
> **制定基准**：深度对标与演进自《Aegis 私密卡牌互动 App 全流程工程研发与交付治理实践规范》  
> **适用范围**：学习通 VPS 自动化后台挂机服务（XXT-VPS Automation Engine）全生命周期研发、测试、部署与运维  
> **核心目标**：根除根目录散乱、命名无序、暗账补丁、排障不可溯等工程乱象，建立高可用、高确定性、零回归、安全防风控的专业级工程体系。

## 一、规范总则与对标治理演进

### 1.1 治理背景与工程痛点审计
在本项目前期探索与 Agent 演进过程中，随着从本地油猴脚本（`v3_optimized.js`）向 Linux VPS 常驻 Playwright 无头后台服务转型，积累了大量宝贵的技术实现，但同时也暴露出以下典型工程混乱痛点：
1. **根目录平铺散落与视觉污染**：根目录下散落了十余张调试截屏（如 `vps_antispider.png`、`vps_captcha_current.png`、`vps_playing_now.png` 等），与核心设计文档、源码目录混杂在一起，缺乏结构化归类。
2. **文档命名无序且无统一字典**：现有文档如 `学习通VPS自动化挂机服务_架构与技术设计文档.md`、`学习通播放器暂停冲突与反爬重定向异常技术分析与排障文档.md` 采用长中文命名，缺少标准工程类型代码、唯一项目前缀及严谨的版本标识。
3. **运行时临时资产与静态工程资产边界模糊**：排障截屏、临时日志、验证码图片属于“动态运行时诊断产物”，但目前直接混入版本库根目录，缺乏自动化清理与归档生命周期。
4. **安全与风控凭证泄露隐患**：学习通账号 Cookie、VPS 远程连接凭证、Session 缓存等敏感信息若无严格的分层与脱敏治理，易发生安全暗账。

### 1.2 对标 Aegis 核心工程哲学
全面继承《Aegis 私密卡牌互动 App》工程规范的六大精髓，并针对**无头爬虫、反爬对抗、远程 VPS 部署与守护进程**这一领域特性进行深度特化演进：

│  四段式语义版本命名公式       │   ──────>    │ XXT_[类别]_[功能]_[版本] 字典│
├──────────────────────────────┤              ├──────────────────────────────┤
│  PRD/TECH/QA/Handbook 四联体 │   ──────>    │ PRD/TECH/OPS/QA/INCIDENT 体系│
├──────────────────────────────┤              ├──────────────────────────────┤

## 三、文件命名语法体系 (Naming Convention)

项目中所有文档、脚本、测试用例与数据文件，均严格遵循四段式标准命名公式：

$$\mathbf{[项目前缀]_[类别代码]_[模块或主题描述]_[版本号].[扩展名]}$$

### 3.1 命名要素细则
1. **项目前缀 (Project Prefix)**：统一固定为大写字母 **`XXT`**（代表 XueXiTong 自动化工程）。
2. **类别代码 (Category Code)**：大写英文字母，明确标识该文件的工程角色（见下文代码字典）。
3. **模块或主题描述 (Topic Description)**：
   - 使用简明精准的中文字符或连字符驼峰表示；
   - **严格禁止**包含中英文括号（如 `()`、`（）`）、空格、问号及特殊符号；
   - 单词或意群之间统一使用下划线 `_` 连接。
4. **版本号 (Version Tag)**：
   - 规范格式为 `vX.Y`（文档/规格书）或 `vX.Y.Z`（系统源码/核心规范）；
   - 正式基准版以 `.0` 结尾，中间修订版递增次版本号；
   - 临时排障截图可使用时间戳 `YYYYMMDD_HHMM` 替代版本号。

## 五、切片式开发与 S-R-A-S 零回归排障闭环

自动化挂机服务极其敏感脆弱，超星前端代码的一个微小更新都可能导致选择器失效或触发风控。严禁不切片、无验证的“大一统盲写”。

### 5.1 纵向切片式开发法 (Vertical Slice-Driven Iteration)
将系统演进拆解为可独立验证的纵向切片：

```
[Slice 1: 环境与守护基座]
  Linux VPS 环境配型 + Playwright 依赖 + Systemd 常驻服务 + 本地网络连通
  验收: 服务端自启正常，无头浏览器正常启动且不崩溃

[Slice 2: 核心会话与登录穿透]
  扫码登录二维码生成 + Cookie 持久化存储 + 失效探测与重定向
  验收: 本地 App 扫码后服务端秒级捕获登录态并落盘

[Slice 3: 播放引擎与 Hook 注入]
  深层 Iframe 深度穿透 + Video.js 播放驱动 + 防失焦/防暂停全量劫持
  验收: 视频进入后平稳播放，后台失焦不中断，播放进度线性增长

[Slice 4: 人机协同与远程控制台]
  Express API 路由 + 实时屏幕快照推流 + 远程倍速/换集交互面板
  验收: 手机/PC 浏览器打开控制台能实时看到挂机画面并下发控制命令

[Slice 5: 风控自愈与异常防护]
  9010 操作异常探测 + 弹题识别 + 验证码浮层中继 + 熔断保护机制
  验收: 遭遇验证码时前端实时告警并接收打码，答码完成后自动恢复播放
```

### 5.2 S-R-A-S 自动化缺陷根因排障闭环

遇到播放暂停、风控拦截或连接超时等缺陷时，强制执行四步闭环标准：

```
1. Symptom (现象锁定与快照抓取)
   - 捕获异常触发瞬间的无头浏览器完整截图 (抓拍落盘至 05_测试与验收_QA/screenshots/)；
   - 导出当前页面的 DOM 结构树快照与 Console 报错日志；
   - 记录触发时的精确时间戳、课程节点与网络请求状态。

2. Root Cause (机理级根因剖析 - 严禁浅层伪修复)
   - 深度挖掘底层技术机理。例如：
     * 表面现象：视频打开即暂停；
     * 浅层伪修复（严厉禁止）：用 setInterval 疯狂每秒调用 video.play()；
     * 深度根因机理：超星后端下发 9010 风控重定向，页面被强制导航至验证码承载页，
       原生 video 实例已被销毁，强行 play() 导致内存泄漏与频繁报错。

3. Automation (自动化断言先行)
   - 在修改源码前，编写 Playwright 自动化测试脚本模拟重现此异常；
   - 增加针对该场景的断言条件（例如：检测到 URL 包含 `antispider` 时必须阻断播放器轮询，
     并向控制台推送 `NEEDS_CAPTCHA` 事件）；
   - 验证修复方案在测试用例下 100% 通过。

4. Sync (四重文档同频沉淀)
   - 沉淀一份 `XXT_INCIDENT_[模块]_[问题描述]_v[X.Y].md` 排障报告；
   - 更新 `03_技术方案` 中的状态机流转图；
   - 更新 `04_资产与数据` 中的选择器或 Hook 字典；
   - 提交符合 Conventional Commits 规范的语义化 Git 记录。
```

## 六、运行时诊断资产（截图与日志）治理规范

针对当前根目录下堆积大量 `vps_*.png` 文件的严重痛点，制定本项**运行时资产治理专项规范**：

### 6.1 截图落盘隔离规则
1. **严禁写入根目录**：无头浏览器运行时抓取的诊断截图、验证码切片、推流快照，**一律禁止保存在工程根目录下**。
2. **存放目录分级**：
   - 临时实时推流（用于前端展示，高频覆盖）：写入系统临时目录或 `vps-service/public/cache/live.png`（并在 `.gitignore` 中忽略）；
   - 关键排障归档截图（发现 Bug 或验证码时固化的证据）：统一写入 `05_测试与验收_QA/screenshots/`；
   - 历史过期的截图：定期清理或打包压缩归入 `99_历史归档_Archive/screenshots/`。

### 6.2 截图标准化命名
排障类截图统一采用命名规范：
$$\mathbf{XXT\_SCREEN\_[场景或状态]\_[时间戳]\_[序号或哈希].png}$$
- **范例**：

## 七、安全准则与敏感凭证治理规范

由于本项目直接涉及用户教育平台账号隐私及远端 Linux VPS 主机安全，设立以下**不可逾越的安全红线**：

1. **凭证脱敏与环境变量隔离**：
   - 严禁将 VPS 登录私钥、SSH 密码、公网 IP、学习通账号密码明文写入代码或文档；
   - 必须通过本地 `.env` 文件读取凭据，`.env` 必须加入 `.gitignore`，版本库中仅提交脱敏模板 `.env.example`。
2. **Cookie 与 Session 数据保护**：
   - 扫码登录产生的 Cookie 与 LocalStorage 数据仅能保存在受保护的本地配置目录，权限设置为 `600`；
   - 文档与示例中如需引用网络请求，必须对敏感字段（`UID`、`_d`、`vc3`、`token`）进行打码脱敏（如 `_d=ab83****9a`）。
3. **VPS 最小权限与网络防火墙**：
   - Web 控制台默认绑定 `127.0.0.1`，仅通过 SSH 端口转发或反向代理鉴权访问；
   - 严禁将无密码保护的控制台端口直接暴露在公网 IP 上。
