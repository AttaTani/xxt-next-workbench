## 1. 业务愿景与用户故事 (Vision & User Story)

### 1.1 业务愿景
让超星自动化巡航系统摆脱“平台一改版脚本就瘫痪”的行业通病，具备如同生物体一样的**免疫、诊断与自我修复机制**。在无人值守的挂机环境中，即使用户在深夜睡觉，面对平台 DOM 选择器突变，系统也能在沙盒内安全合成热补丁，通过五道防爆门禁验证后无缝热生效，保障 7×24 小时零中断平稳运行。

### 1.2 核心用户故事 (User Story)
- **As a** 长期挂机用户 / 多租户运维者
- **I want** 系统在遇到未知的前端改版或试卷提取失败时，能够自动诊断原因并原地修复，而不是直接卡死或跳过未做题目
- **So that** 我无需每天手动查看控制台、无需等待开发者更新发布新版本，全科目的章节作业与随堂测验都能 100% 自动稳定完成。

## 2. 功能特性矩阵 (Feature Matrix)

| 编号 | 功能模块 | 优先级 | 核心能力描述 | 验收指标 |
| :--- | :--- | :--- | :--- | :--- |
| **F-S1-01** | **事故现场无损快照** | P0 | 当试题提取结果为空或选择器超时时，毫秒级序列化 Frame 内 DOM 树并保存报错快照。 | 生成包含 DOM、URL、时间戳的无损事故 Dump 包。 |
| **F-S1-02** | **五道防爆安全门禁** | P0 | 严密设防：隔离沙盒运行、AST 语法树白名单审查、`node --check` 语法检验、离线历史基准 100% 回归、毫秒级熔断器。 | 100% 拦截非法代码注入与危险系统调用，杜绝“AI 乱修修崩项目”。 |
| **F-S1-03** | **LLM 代码诊断专家** | P0 | 结构化输入故障现场 DOM 片段，引导大模型分析类名变异规律，输出严格受控的 JSON 规则补丁。 | 生成可用 CSS/XPath 规则补丁，单次生成耗时 $<3\text{s}$。 |
| **F-S1-04** | **动态内存热重载** | P0 | 补丁通过五道门禁后，内存中的规则管理器（`RuleManager`）原子化热替换，主服务与挂机进程零重启。 | 热替换延迟 $<10\text{ms}$，现有任务无感继续作答。 |
| **F-S1-05** | **自动熔断与原子回滚** | P1 | 若热补丁生效后连续 2 次再次发生异常，系统自动触发熔断回滚至稳定基线，并通知运维。 | 自动回退至基准状态，杜绝死循环消耗 Token。 |

## 3. 非功能性需求与安全防线 (Non-Functional & Security)

1. **绝对安全（Blast Radius Limit）**：自进化引擎严禁改写主进程 `taskWorker.js` 的核心状态机逻辑，所有补丁只能在解耦的 `selectors.json` 规则集内进行并集融合（Merge）。
2. **零停机（Zero Downtime）**：热修复全流程不中断 Chromium 浏览器实例，不销毁已有页面上下文。
3. **零回归（Zero Regression）**：任何热补丁必须在内置的 5 套基线 Mock 试卷上跑出 100% 提取准确率，绝不允许“按下葫芦浮起瓢”。
