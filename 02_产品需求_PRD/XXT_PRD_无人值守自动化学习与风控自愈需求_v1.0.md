## 1. 业务背景与用户价值

### 1.1 背景痛点
超星/学习通网课学习场景中，学员面临课程周期长、任务点分散、视频穿插随机答题、浏览器后台失焦自动暂停等痛点。传统基于本地浏览器的油猴插件存在“电脑休眠即中断、网络闪退无法自愈、窗口最小化触发检测”等根本性缺陷。

### 1.2 核心目标
构建一个运行于远程 Linux VPS 上的 7×24 小时高可用自动化后台学习引擎，支持：
1. **远程扫码授权**：通过轻量 Web 面板远程展示二维码，支持移动端学习通扫码即时登录与 Session 凭据持久化。
2. **多层 Iframe 深度穿透**：全自动识别课程章节树、探测多层嵌套播放器并自适应驱动播放。
3. **零误触防作弊仿真**：阻断浏览器原生 `blur`、`visibilitychange` 被动暂停机制，模拟真人学习行为。
4. **风控异常熔断与远程人机协同**：遭遇【9010 操作异常】反爬拦截时，主动熔断休眠、降级并向控制台推送验证码进行人工/OCR 自愈，防止账号被平台升级封禁。

## 2. 功能矩阵与优先级 (Feature Matrix)

| 需求模块 | 功能描述 | 优先级 | 验收基准 |
| :--- | :--- | :--- | :--- |
| **会话管理** | 扫码登录与 Cookie 持久化 | P0 | 扫码后 3 秒内完成登录态捕获，重启服务免扫码 |
| **播放控制** | 视频播放与任务点流转 | P0 | 自动识别小节视频，播放完毕自动跳入下一未完成章节 |
| **防失焦劫持** | 浏览器事件被动暂停拦截 | P0 | 后台最小化或切换标签页时，视频进度持续推进 |
| **远程控制台** | 实时画面推流与参数调控 | P1 | Web 面板实时渲染当前画面快照，支持倍速 (1.0~2.0) 调节 |
| **风控熔断器** | 9010 反爬拦截主动止血 | P0 | 连续触发 2 次验证码自动挂起 10 分钟，禁止无脑死循环 |
| **人机协同打码**| 验证码弹窗中继与远程提交 | P1 | 前端浮层显示验证码图片，提交答案后自动注入恢复播放 |
| **弹题自愈** | 视频内置随堂测试识别 | P2 | 弹题时自动暂停播放，尝试匹配选项或告警通知人工 |

## 3. 非功能性需求与合规边界 (Non-Functional Requirements)

1. **拟真学习基线 (Human Simulation)**：
   - 默认播放倍速不得超过 1.5 倍（风控严查期强制 1.0 倍）；
   - 章节跳转间随机延迟 3~8 秒，模拟人类点击决策。
2. **安全隔离原则 (Zero Leakage)**：
   - 严禁将用户真实账号与 Cookie 提交至公开代码仓库；
   - Web 控制台仅对受信任 IP 或内网转发开放。
