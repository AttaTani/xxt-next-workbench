## 2. 根因深度剖析 (Deep Root Cause Analysis)

经过对模型交互日志、DOM 结构与执行栈的逐帧反查，本故障由 **4 个链式缺陷（Defect Cascades）** 复合诱发：

```
┌────────────────────────────────────────────────────────────────────────┐
│ 缺陷 1：Prompt 提示词歧义 ──> 模型误将题型当答案，返回字符串 "判断题" │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 缺陷 2：正则提取与降级设计漏洞 ──> 正则匹配不到 A-D/对/错，兜底返回 "判断题" │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 缺陷 3：DOM 匹配脱靶 ──> "判断题" 无法匹配 "A、对" 或 "B、错"，命中为 null │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 缺陷 4：无状态盲选 Option 0 ──> 触发兜底盲选 A，答错后每 3s 重复盲选 A 死循环 │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
                     【超星判定连续答错超限，强行踢出】
```

### 2.1 缺陷 1：Prompt 歧义导致模型分类漂移 (Semantic Drift)
原有 Prompt 描述：
> *“这是一道中国大学在线课程视频中的随堂测验题。请仔细识别图片中的题目内容和所有选项（单选、多选或判断题），直接给出正确答案的选项字母或对错……”*

- **模型误读**：Prompt 中包含了“（单选、多选或判断题）”，而超星测验弹窗左上角恰好赫然印着 **`判断题`** 三个大字；
- **输出漂移**：多模态大模型判定用户是在要求其“识别题型”或“输出题型”，因此模型直接返回了文本：`"判断题"`。

### 2.2 缺陷 2：正则匹配归一化漏洞 (Regex Fallback Flaw)
原有代码：
```javascript
const content = data.choices?.[0]?.message?.content?.trim() || '';
const match = content.match(/([A-D]|对|错|正确|错误)/i);
return match ? match[0].toUpperCase() : content;
```
- 当 `content` 为 `"判断题"` 时，不包含字母 A~D，也不包含“对/错/正确/错误”；
- `match` 返回 `null`；
- 三元运算符 `return match ? match[0] : content` **兜底返回了原字符串 `"判断题"`**！

### 2.3 缺陷 3：DOM 选项映射完全脱靶 (DOM Mapping Failure)
选项匹配代码期望输入为字母（A/B/C/D）或“对/错”：
```javascript
for (const l of labels) {
    if (text.startsWith(ans) || text.includes(ans)) { ... }
}
```
页面上的选项为 `A、对` 和 `B、错`，没有任何一个选项以 `"判断题"` 开头或包含 `"判断题"`。
因此 `clickedText` 返回 `null`，AI 答题模块**实际未点击任何选项即宣告失败**！

### 2.4 缺陷 4：无状态试错盲区导致每 3 秒重复提交错误答案 (Stateless Trial Storm)
由于 AI 模块未命中任何选项，执行流漏入底层兜底逻辑：
```javascript
// 兜底逻辑：无记忆状态盲选
let targetOpt = quizOptions[0]; // 永远选第 0 项 (A、对)
if (wrongTip && quizOptions.length > 1) {
    targetOpt = quizOptions[1];
}
targetOpt.click();
submitBtn.click();
```
- **核心盲点**：超星播放器内部提示“回答错误”后，下一次轮询并没有跨周期记忆“选项 A 已经试过且错误”。
- **风暴死循环**：每隔 3 秒监控轮询一次，AI 再次返回 `"判断题"`，兜底逻辑再次强行勾选选项 A 并提交。
- **超星惩罚**：在 30 秒内连续提交 11 次错误答案，播放器达到错误上限，直接触发页面重定向踢出至 `i.chaoxing.com/base`！

## 3. 体系化重构与根治方案 (Systemic Remediation Strategy)

为了从根源上消灭“模型答题跑偏、无法点击、死循环盲选”问题，建立四级防御与治理机制：

### 3.1 治理 1：零歧义结构化 JSON 提示词协议 (Strict JSON Prompt Protocol)
彻底废弃自由文本问答，强制要求模型返回严格的 JSON 结构，并明确剥离题型干扰：

```json
{
  "question": "陈胜起义之后，会稽太守首先对起义进行镇压",
  "choice": "B",
  "reason": "会稽太守殷通欲响应起义，但被项羽所杀"
}
```

**更新后的精准 Prompt**：
```
你是一个专业的在线课程答题助手。图片中是一道随堂测验。
请严格分析题目事实，找出正确答案。
【极其严格的格式要求】：
你必须且只能输出答案的选项英文字母（如 'A'、'B'、'C' 或 'D'）。
如果是判断题，请根据页面选项输出对应的 'A' 或 'B'。
严禁输出'判断题'、'单选题'、'题目'等任何中文字样！
严禁输出任何解释、标点或多余字符！
输出示例：
B
```

### 3.2 治理 2：黑名单清洗与二阶正则提取器 (Sanitizer & Second-Stage Extractor)
在解析模型返回值时，先执行黑名单清洗，过滤一切干扰词汇：

```javascript
cleanContent(raw) {
    let text = (raw || '').trim();
    // 1. 过滤题型与问答干扰词
    text = text.replace(/判断题|单选题|多选题|题目|答案|正确答案|选项|选择/g, '').trim();
    
    // 2. 优先提取单个英文字母 A/B/C/D
    const letterMatch = text.match(/\b([A-D])\b/i) || text.match(/([A-D])/i);
    if (letterMatch) return letterMatch[1].toUpperCase();

    // 3. 次优提取汉字 对/错/正确/错误
    if (text.includes('对') || text.includes('正确')) return 'A'; // 超星判断题通常 A 为对
    if (text.includes('错') || text.includes('错误')) return 'B'; // 超星判断题通常 B 为错

    return null; // 无法解析时显式返回 null，绝不回传脏文本
}
```

### 3.3 治理 3：有状态排除法试错机 (Stateful Exclusion Machine)
在 Worker 内存中维护针对当前测验弹窗的“试错排除状态机”：
- 为当前题目生成指纹（根据题目文本或出现时间戳）；
- 记录 `attemptedOptions = new Set()`；
- **试错规则**：
  - 第 1 次尝试：AI 推荐选项（例如 B）；
  - 若提示“回答错误”：将 B 计入已试黑名单，**下一次尝试强制选择未尝试过的选项（例如 A）**；
  - **最大试错上限熔断**：单题最多尝试选项总数（判断题最多 2 次，单选题最多 4 次）。若全部试错均未通过，**主动暂停挂机并触发 Windows Toast 强提醒，严禁无休止重复轰炸**！

### 3.4 治理 4：重定向拦截器深度加固 (Hardened Navigation Guard)
在播放页面中加固全局跳转拦截：
```javascript
// 阻断任何向 i.chaoxing.com/base 或非播放页的跳转
window.addEventListener('beforeunload', (e) => {
    if (document.querySelector('.ans-videoquiz')) {
        e.preventDefault();
        e.returnValue = '';
        return false;
    }
});
```
